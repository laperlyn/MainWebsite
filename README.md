# La Perlyn
Images are already in `images/` (hero.jpg + p1–p16). To add a saree: add a row to `RAW` in `data.js` and save `images/pN-1.jpg` (optional `pN-2.jpg` for a hover image — set the 7th value to 2).
Run: open `index.html`, or `npm install && npm start` for the order backend (http://localhost:3000).
